Como Funciona
Es una herramienta que analiza las relaciones y permisos dentro de Active Directory y los dibuja en forma de mapa o red.

Pasos de la Prueba
Se recolecta la información del dominio utilizando un script conectado con un usuario válido.

Se cargan los datos en la aplicación para visualizar los caminos cortos que llevan a un usuario común a convertirse en administrador total.

Como Protegerse
Revisar frecuentemente los permisos avanzados de los objetos para que nadie tenga privilegios innecesarios sobre otros usuarios o grupos.
