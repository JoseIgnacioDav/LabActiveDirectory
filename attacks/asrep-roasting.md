Como Funciona
Es un ataque dirigido a usuarios que no requieren una clave previa de seguridad (preautenticación) para pedir datos al servidor.

Pasos de la Prueba
Se usa una lista de nombres de usuario para buscar cuentas con esta debilidad desde la computadora atacante.

El servidor entrega un archivo cifrado con la clave del usuario vulnerable.

Se lleva ese archivo a otra computadora para intentar adivinar la contraseña probando muchas opciones offline.

Como Protegerse
Desactivar la opción de permitir accesos sin preautenticación en las propiedades de las cuentas de usuario de Active Directory.
