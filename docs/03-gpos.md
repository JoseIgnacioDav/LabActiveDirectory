Reglas de Seguridad (GPOs)
Las directivas de grupo sirven para aplicar normas a todas las computadoras y usuarios del dominio:

Contraseñas: Se definen reglas básicas de longitud y complejidad, manteniendo algunas debilidades controladas para poder hacer prácticas de auditoría.

Registro de eventos: Se activa el guardado detallado de los movimientos importantes que ocurren en el servidor.

Restricciones de red: Se bloquean accesos anónimos para evitar que personas sin permisos consulten información interna.
