Red y Maquinas
El laboratorio utiliza una red interna aislada para evitar riesgos externos. La red es la 192.168.56.0/24 y el dominio se llama corp.local.

DC01: Windows Server con la IP 192.168.56.10. Funciona como el servidor principal que maneja el dominio y las direcciones de red (DNS).

Client01 y Client02: Computadoras con Windows para simular a los usuarios de una oficina unidos al dominio.

Kali Linux: Computadora usada para realizar las pruebas de seguridad y auditoría.
